# Roco Index

- Use local development and local previews. Do not publish or host this app using OpenAI's Sites service unless the user explicitly requests it.
- Keep interface copy concrete. Do not add decorative taglines, slogans or filler microcopy.
- Reuse existing components and helpers: `Modal.tsx`, `Artwork.tsx`, `data.ts`, `bundles.ts`, `compendium.ts`, `localization.ts` and `workspace.ts`.
- Preserve original Chinese text, separate English translations, stable record IDs and saved-state formats. Do not infer cross-region identities or game mechanics from artwork.
- Run `npm run build` for substantive app changes and visually check affected desktop/mobile layouts.
- Preserve third-party copyright notices, licences and credits.
- Keep credentials, personal browser data, local research and build output out of Git.

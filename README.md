# Roco Index

An independent Roco Kingdom fan companion built with Vite, React and TypeScript.

- Search creatures, skills, traits and recorded locations.
- Plan teams, compare stats and track your collection.
- Browse character artwork, desktop/mobile wallpapers, music and official news.
- Switch between English translations and the original Chinese reference text.
- Keep personal teams, notes and collection progress in your browser; export backups to move them between devices.

## Development

```sh
npm ci
npm run dev
```

`npm run build` checks TypeScript and builds the app. `npm run preview` serves that build locally. The prepared data and media are included; no database, account or API key is required.

## Contributions

## Data and credits

The creature reference is a dated Chinese-region snapshot. Values may differ from the global game. English translations are unofficial except for the explicitly matched official names; the original Chinese text is retained alongside them in the data files.
